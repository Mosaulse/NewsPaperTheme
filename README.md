## 安装方法

### 从 VS Code 市场安装（推荐）

1. 打开 VS Code
2. 前往扩展市场（Ctrl+Shift+X）
3. 搜索 "Newspaper Theme"
4. 点击安装

### 本地安装（.vsix 文件）

1. 下载 `.vsix` 安装包
2. 打开 VS Code
3. 按 `Ctrl+Shift+P` 打开命令面板
4. 输入 "Install from VSIX..." 并选择
5. 选择下载的 `.vsix` 文件

## 激活主题

1. 按 `Ctrl+K Ctrl+T` 打开主题选择器
2. 选择 **Newspaper Light** 或 **Newspaper Dark**

## 特色

- 📰 **双色系**：Light 模拟泛黄报纸，Dark 模拟浓墨宣纸
- 🖋️ **高对比度**：WCAG AA 合规，长时间编码不累眼
- 🎨 **25 条语法高亮规则**：覆盖主流编程语言
- 🔧 **144+ UI 属性**：完整定制 VS Code 界面
- 🏛️ **中国美学**：青花蓝、朱砂红、赭石褐、暗金古铜
